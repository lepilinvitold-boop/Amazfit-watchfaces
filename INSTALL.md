# Циферблаты для Amazfit Balance 2

Сохранены версии Owl Steel 0.94.6, Owl Steel 0.94.5, SDDC639Ru 2.7.1 (Lime) и SDDC639Ru 2.6.1 (красная секундная стрелка).

| Owl Steel 0.94.5: объёмный металлический безель, светлые деления | [QR](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/Owl-Steel-v0.94.5-install-qr.png) | [ZPK](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/Owl-Steel-v0.94.5-RU-Balance2.zpk) |
| SDDC639Ru 2.7.1: Lime секундная стрелка | [QR](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/install-qr-v2.7.1.png) | [ZPK](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/SDDC639Ru-Balance2-v2.7.1.zpk) |
