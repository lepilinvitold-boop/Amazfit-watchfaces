# Инструкции для работы с циферблатами

Перед правками прочитать docs/WATCHFACE-RU.md и README выбранного проекта. Последняя принятая Graphite 2 — projects/Graphite-Arm-1.1.7 (code21), подтверждена пользователем 2 ноября 2026. Для работ над Graphite 2 использовать её. Отдельная ранее принятая «Графит-арм»1.0.9 и её базовые ресурсы сохранены; другие проекты не менять. Не использовать удалённые промежуточные версии.

Сохранять согласованные элементы вне запроса. Проверять отступы численно и визуально, длины шкал с учётом толщины, крайние данные, normal/AOD и реальные зоны тапов. Не выдавать модельные проверки за запуск на часах. После изменения и принятия обновлять рабочую инструкцию.
