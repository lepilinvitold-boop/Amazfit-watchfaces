# Циферблаты для Amazfit Balance 2

Сохранены только версия 2.7.1 и базовая версия 2.6. Версия 2.6 — основа последующих модификаций.

| Вариант | Установка через Zepp | Скачать |
| --- | --- | --- |
| 2.7.1: Lime секундная стрелка, узкий двухчастный безель и светлые мелкие деления | [QR](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/install-qr-v2.7.1.png) | [ZPK](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/SDDC639Ru-Balance2-v2.7.1.zpk) |
| 2.6: базовая исправленная версия с красной секундной стрелкой | [QR](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/install-qr-v2.6-fixed.png) | [ZPK](https://raw.githubusercontent.com/lepilinvitold-boop/Amazfit-watchfaces/main/dist/SDDC639Ru-Balance2-v2.6-fixed.zpk) |

Откройте QR на планшете и отсканируйте его сканером Zepp в режиме разработчика на телефоне, подключённом к часам.

Исходные пакеты находятся в source/. Остальные версии удалены из текущих файлов проекта; история Git сохранена.
