# Heiyan RU 1.0.0 для Amazfit Balance 2

Адаптация Heiyan. Исходные изображения часовой, минутной и секундной стрелок сохранены.
Полный приглушённый AOD показывает показатели и время без секунд.
Строка под временем открывает будильники. Время ближайшего системного будильника не предоставляется проверенным API циферблата и обозначено прочерком. Штатный значок отображает статус будильника.

Сборка из исходного пользовательского ZIP: `python source/build.py путь/к/heiyan_balance.zip`.
Требуются Pillow, NumPy и шрифт DejaVu Sans Bold. Работа на физических часах ещё не проверена.
