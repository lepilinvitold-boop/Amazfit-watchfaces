# Графит-арм 1.1.2

Основа JS: 1.1.1 (8cf8af29be66d8deb164d38536edb07a792029a1). Базовые ресурсы: сохранённая 1.0.9, SHA256 76b71a4aa2fe45c2ef30198df503626ebbecf82c2ac1365290d2cb95e01f507e. appId10623141 сохранён; versionCode13. Установка обновляет этот проект.

По согласованию пользователя: нижняя левая шкала теперь расстояние с нативными TEXT_IMG/IMG_LEVEL DISTANCE; нижняя правая — калории с нативным TEXT_IMG CAL и заполнением current/target датчика CALORIE. TRAINING_LOAD удалён из этой версии. Цифры всех четырёх шкал используют неизменённые arc_0..9: DejaVu Sans Bold25, ширина14, общая высота ресурсов; размер и насыщенность одинаковы. Нижние значения горизонтальные для штатной привязки расстояния без предположений о единицах сырых датчиков. Единицы км/ккал; предусмотрены мили при имперских настройках. Надписи стоят внутри секторов между кругами и заполнением: x80 и300, y310, w100. Они не являются процентами. При отсутствии данных — прочерк. Ноль остаётся корректным значением. Нативный IMG_LEVEL DISTANCE использует интерпретацию прогресса прошивки; своя выдуманная цель по расстоянию не задана.

Стресс и его прямые тапы StressHomeScreen, цветовые пороги батареи/стресса, круги, безель, стрелки, время/дата и погода сохранены. 21 непересекающаяся тап-зона. Нижние зоны IMG_CLICK DISTANCE и CAL. AOD содержит те же значения в приглушённом виде, без тапов и секундной стрелки.
