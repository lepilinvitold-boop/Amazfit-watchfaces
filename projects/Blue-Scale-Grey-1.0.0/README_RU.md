# Blue Scale Grey 1.0.0 — Amazfit Balance 2

Отдельный проект, appId 10622131. Чёрный фон, стальные выпуклые контуры, четыре информационных круга, безель из принятой Grey Volume 1.0.1. Компоновка адаптирована по одобренному эскизу, точные текстуры эскиза не копируются.

Данные: погода, пульс, шаги, дата и день недели, батарея, дистанция, калории; аналоговое время и цифровое HH:MM. Все цифры динамические; эскизные значения не зашиты в сборку.

9 зон: батарея → управление батареей; погода → погода; пульс → пульс; шаги/дистанция/калории → соответствующие нативные показатели; дата → календарь; часы цифрового времени → секундомер; минуты → таймер.

Полный AOD: вся композиция и данные в затемнённом виде, без секундной стрелки и активных тапов. Фактическую частоту обновления AOD определяет прошивка.

Проверка: node validate.cjs ../../verify-blue-scale-grey. Автоматически проверены ресурсы, 9 непересекающихся зон, маршруты, HH:MM, отсутствие секунд в AOD, обработка отсутствующего пульса, повторная инициализация и очистка обработчика. Сборка не запускалась на физических часах. Нативные экраны и динамические показания требуют проверки после установки.

Сборка: python build.py. Используются Pillow, NumPy, ReportLab и исходный Grey пакет в dist. Не редактировать предыдущие проекты.
