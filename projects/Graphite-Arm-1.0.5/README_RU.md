# Графит-арм 1.0.5 — Amazfit Balance 2

Все правки из согласованного превью: широкая объёмная металлическая площадка, фаски и тени; изогнутое время HH:MM:SS 28 px под батареей и дата ДД.ММ ДЕНЬ 23 px над погодой в серебристых рамках. Внешние подписи 17 px, проценты 16 px; батарея — процент заряда, шаги/калории — процент дневной цели, пульс — уд/мин. В кругах сохранены основные значения. Мин./макс. температуры 25 px, разделены тире, строка поднята до y=386.

appId 10623141 сохранён: обновление Графит-арм, отдельно от Blue Scale Grey. Полный AOD с приглушением, время HH:MM без секунд, секундная стрелка отключена. Активная секундная обновляется каждые 50 мс; цифровые секунды обновляются при смене значения. При pause таймер останавливается, при resume показания обновляются.

Символы времени и даты заранее повернуты в отдельных ресурсах; при смене показаний обновляется только SRC. Обновление даты, включая переход года, проверяется в validate.cjs. Физическая проверка на часах пользователем необходима.

Сборка: python3 projects/Graphite-Arm-1.0.5/build.py
Проверки: node projects/Graphite-Arm-1.0.5/validate.cjs verify-graphite-arm-105
python3 projects/Graphite-Arm-1.0.5/check_layout.py
Зависимости Python: Pillow, numpy, scipy, reportlab. Исходные ресурсы Blue Scale Grey 1.0.10 и Grey Volume 1.0.1 остаются зависимостями сборки.
