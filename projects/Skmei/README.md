Тап по оси стрелок открывает будильник. Минуты открывают секундомер, секунды — обратный отсчёт.

Красный цвет: активный будильник, заряд ниже 20%, значок пульса выше 100 уд/мин. Шаги и калории сравниваются с целями часов, PAI — с 100 баллами, стресс меняет цвет с 60. Порог пульса относится к оформлению циферблата.

Пакет и логика проверены локально. Установка и работа на физических часах ещё не подтверждены.
