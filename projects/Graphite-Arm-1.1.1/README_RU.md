# Графит-арм 1.1.1

Обновление 1.1.0 по запросу пользователя. appId 10623141 сохранён, versionCode 12.

Изменения:
- Удалён BioCharge: на скриншоте физических часов пользователя (45953.png, 01.11.2026) нижний правый сектор полностью отсутствовал. Причина не установлена; модельные тесты 1.1.0 не подтверждали его работу на часах.
- Нижняя правая шкала теперь использует штатный TRAINING_LOAD. Число — отдельный нативный TEXT_IMG, без процента; invalid_image — прочерк, а не искусственный ноль. Цифры 25px из прежнего arc-шрифта. Положение x314,y340,w76,h24; горизонтальное для точного нативного отображения. Проверены 0..9999.
- Фоновая дорожка видна независимо от наличия данных. Штатный IMG_LEVEL содержит 3 уровня low/moderate/high, как imageProgressCount:3 в официальном редакторе Zepp. Это категории нагрузки, а не процент цели. Ресурсы используют прежнюю геометрию правой нижней шкалы.
- Три нижние правые зоны IMG_CLICK TRAINING_LOAD открывают данные нагрузки штатным способом.
- Пользователь сообщил, что зона стресса в 1.1.0 не открывает приложение. Три верхние правые зоны заменены BUTTON со startApp({url:'StressHomeScreen',native:true}); маршрут взят из ранее сохранённого Owl Graphite. На часах эта новая версия ещё не проверена.
- Цветовые пороги 1.1.0, круги, стрелки, погода, время/дата, AOD и остальные зоны сохранены.

Официальные основания: https://docs.zepp.com/docs/watchface/api/hmUI/widget/data_type/ ; https://docs.zepp.com/docs/watchface/api/hmUI/widget/TEXT_IMG/ ; экспорт TRAINING_LOAD, invalid_image, jumpable и imageProgressCount:3 в https://watchface.zepp.com/static/js/main.6bfe2884.chunk.js (проверено 01.11.2026).
