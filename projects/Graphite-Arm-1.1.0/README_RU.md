# Графит-арм 1.1.0

Основа: принятая 1.0.9, SHA256 76b71a4aa2fe45c2ef30198df503626ebbecf82c2ac1365290d2cb95e01f507e. appId 10623141, versionCode 11: обновление того же циферблата.

Внешняя шкала батареи и её проценты: приглушённый красный при заряде <20%; круг батареи не изменён. Внешняя шкала шагов и проценты: приглушённый зелёный при выполнении цели >=100%. Внешний пульс заменён стрессом, 1–100 баллов, с приглушённым синим при >=80; 0/невалидные данные — прочерк. Пульс внутри правого круга сохранён. Нижняя правая шкала — штатный BioCharge 0–100 баллов без знака процента, нажатие открывает BIO_CHARGE. На верхнюю правую шкалу добавлены три непересекающиеся зоны IMG_CLICK STRESS. Всего 21 зона, только normal.

Официальный источник поддержки BIO_CHARGE: https://watchface.zepp.com/static/js/main.6bfe2884.chunk.js (проверен 01.11.2026), таблица data_type и экспорт image_progress/jumpable; минимальный API_LEVEL поля 4.2. READINESS и расчётные заменители не используются. Если прошивка не предоставляет BIO_CHARGE, показывается прочерк, переход отключён. Наличие реального значения и работа перехода требуют проверки на установленных часах. Модель не эмулирует нативный выбор уровня IMG_LEVEL.

Цвета RGB: красный (181,104,108), зелёный (123,162,133), синий (110,145,183). Затемнение AOD 38%. Исходные ресурсы 1.0.9 сохранены побайтно; добавлены отдельные цветовые варианты, стресс и BioCharge. Геометрия, шрифты, стрелки, внутренние круги не изменены.

Проверки: build.py; node projects/Graphite-Arm-1.1.0/validate.cjs verify-graphite-arm-110; python projects/Graphite-Arm-1.1.0/check_layout.py. Модель проверяет все ресурсы, пороги и обратные переходы, 21 непересекающуюся зону, дату/время, normal/AOD, восстановление пульса и очистку всех listeners/timer. Геометрия: 21 кадр шкал, 101 кадр BioCharge, длинные подписи и 398 температурных случаев. Превью синтетическое, открыто и проверено визуально. Проверки на физических часах не проводились.

Построение превью: node projects/Graphite-Arm-1.1.0/preview_model.cjs verify-graphite-arm-110; python projects/Graphite-Arm-1.1.0/render_preview.py. Пример: батарея19%, шаги100%, стресс86, BioCharge55; все цифры на превью — демонстрационные. Затем повторить build.py для обновления иконки пакета.

1.0.9 остаётся принятой основой до проверки пользователем 1.1.0. Предыдущие версии не удалены.
