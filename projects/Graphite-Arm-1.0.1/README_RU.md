# Графит-арм 1.0.1 — Amazfit Balance 2

Отдельный проект на основе Blue Scale Grey 1.0.10. appId 10623141 (исходный 10622131). Круги: батарея сверху, шаги слева, пульс справа, погода снизу. Цифры 12/3/6/9 удалены. Дата ДД.ММ и день недели одной строкой снизу. Время HH:MM под батареей. Погода: текущая, минимум и максимум. Внешний безель и четыре живые шкалы сохранены. Исходные стрелки 1.0.10, изменены только острия. Широкие объёмные стальные ободки. Дата поднята от шкалы. Симметричные острые стрелки, тёмные узкие противовесы. Полный AOD с приглушёнными данными, без секундной стрелки. Семь зон нажатий.

Проверено: JS в имитаторе API, файлы ресурсов, события шкал, отсутствие пульса и восстановление, AOD, непересекающиеся зоны нажатий, отдельный ID в обоих манифестах. На физических часах не проверено.

Сборка: python3 projects/Graphite-Arm-1.0.1/build.py
Проверка: node projects/Graphite-Arm-1.0.1/validate.cjs verify-graphite-arm

Дополнительно: углублённые металлические перемычки; одинаковый основной шрифт; уменьшенные значки; проверены 10000 шагов; калории заполняются снизу вверх. Плавная секундная: таймер 50 мс, дробный угол по системному времени; остановка при pause/AOD и удалении, запуск при resume. Реальная плавность и расход на Balance 2 требуют проверки на устройстве.
