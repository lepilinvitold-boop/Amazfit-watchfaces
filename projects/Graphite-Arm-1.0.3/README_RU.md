# Графит-арм 1.0.3 — Balance 2

На основе 1.0.2. appId 10623141, отдельный от Blue Scale Grey. Круги симметрично раздвинуты: центры (240,110), (110,240), (370,240), (240,370), радиус от центральной оси 130 px. Прямую живую дату ДД.ММ ДЕНЬ перенесли над нижним кругом, цифровое время подняли на 13 px. Новый компактный силуэт идущего человека. Стрелки, плавная секунда, AOD, шкалы по 50°, направление калорий снизу вверх сохранены.

Сборка: python3 projects/Graphite-Arm-1.0.3/build.py
Проверка: node projects/Graphite-Arm-1.0.3/validate.cjs verify-graphite-arm-103
На физических часах не проверено.

Финальные правки: все основные цифры одним шрифтом 30/18; цифры подняты ещё на 6 px. Значки шагов 21×24, пульса 24×22, погоды 26×26. Батарея 40×18 сохранена.
