# Amazfit Green RU — 1.0.1

Исправленная версия для Amazfit Balance 2, 480×480, appId **10623001**, version.code **2**. Обновляет нерабочую 1.0.0; другие проекты не заменяет.

## Исправления запуска

В 1.0.0 отсутствовал обязательный `app.js`. В 1.0.1 восстановлены bootstrap App, глобальные параметры, WidgetFactory/HmDomApi по подтверждённому рабочему проекту Owl Graphite. Формат изображений приведён к Zepp L8_ARGB8888: 64-байтовый TGA/SOMH заголовок, RGBA палитра с premultiplied alpha и выравниванием ширины до 16 пикселей. Убраны накопленные aod_aod_* ресурсы. Первой создаётся подложка; недоступность дополнительных датчиков не прерывает её отображение.

## Графика

Заново построена по предоставленной фотографии. Восстановлены экранное кольцо, числа на окружности с ориентацией как на фото, хромированные винты, мелкие отметки, три зелёные дуги с зубцами, наклонные узкие часовые цифры, границы секторов, молния, перекрестие, четыре зелёных квадрата, облако, индикаторы и замок. Amazfit помещён непосредственно под 12; MEN удалён. Нижняя панель с плавным плечом, узкие семисегментные цифры времени, стрелки с чёрными продольными прорезями. Корпус и физический внешний безель исходных часов не входят в экранную графику. Это воссоздание, а не извлечение оригинальных ресурсов; абсолютная идентичность фотографии не подтверждена.

## Данные

Нативные виджеты: время, секунды, дата и день недели, температура, заряд. Левый процент — выполнение цели шагов (интерпретация неидентифицированного символа на фото), не процент пульса. Дата в формате ДД/ММ/ГГ; год и процент шагов обновляются через датчики. ДП/ПП — до/после полудня в 12-часовом формате; цифровое время следует настройке часов. Надписи на русском, название Amazfit сохранено латиницей. В AOD нет ни цифровых секунд, ни секундной стрелки; остальные элементы приглушены.

## Сборка и проверки

Python 3: Pillow, numpy, reportlab; Node.js — для validate.cjs. Шрифты NimbusSansNarrow-BoldOblique, NimbusSansNarrow-Regular и NimbusSans-Bold из URW Base35, с поддержкой кириллицы. `python build.py` создаёт assets и dist. `node validate.cjs` проверяет запуск bootstrap, создание виджетов, повторный build, наличие ресурсов, AOD, обновление датчиков, отказ дополнительных датчиков и удаление слушателей. Превью собрано из декодированных ресурсов установочного пакета, с образцовыми показателями.

Проверены JavaScript, внутренняя структура ZPK, размеры, палитры, alpha, пути и программный жизненный цикл. На физических Balance 2 эта сборка ещё не проверена. QR сканировать сканером Zepp в режиме разработчика.
