# Amazfit Green RU 1.0.0

Отдельный проект для Amazfit Balance 2, appId 10623001, 480×480. Дизайн воссоздан по фотографии, а не извлечён из оригинального пакета. Русские подписи, Amazfit под 12, MEN удалена. Зелёная секундная стрелка, аналоговое и цифровое время, секунды, день недели, число и месяц, пульс, заряд, шаги и температура. Нативные виджеты получают значения часов. AOD приглушённый, без секунд.

Сборка: Python 3 с Pillow и numpy, запуск `python build.py`. Шрифт DejaVuSans-Bold с кириллицей. Исходники графики генерируются build.py; watchface.js содержит исполняемый код Zepp.

Проверены структура ZPK, синтаксис JavaScript и существование ресурсов; на физических часах не проверено. QR сканировать сканером Zepp в режиме разработчика.
