# Графит-арм 1.0.2 — Amazfit Balance 2

Отдельный проект на основе Blue Scale Grey 1.0.20. appId 10623141 (исходный 10622131). Круги: батарея сверху, шаги слева, пульс справа, погода снизу. Цифры 12/3/6/9 удалены. Дата ДД.ММ и день недели одной строкой снизу. Время HH:MM под батареей. Погода: текущая, минимум и максимум. Внешний безель и четыре живые шкалы сохранены. Исходные стрелки 1.0.20, изменены только острия. Широкие объёмные стальные ободки. Дата поднята от шкалы. Симметричные острые стрелки, тёмные узкие противовесы. Полный AOD с приглушёнными данными, без секундной стрелки. Семь зон нажатий.

Проверено: JS в имитаторе API, файлы ресурсов, события шкал, отсутствие пульса и восстановление, AOD, непересекающиеся зоны нажатий, отдельный ID в обоих манифестах. На физических часах не проверено.

Сборка: python3 projects/Graphite-Arm-1.0.2/build.py
Проверка: node projects/Graphite-Arm-1.0.2/validate.cjs verify-graphite-arm

Дополнительно: углублённые металлические перемычки; одинаковый основной шрифт; уменьшенные значки; проверены 10000 шагов; калории заполняются снизу вверх. Плавная секундная: таймер 50 мс, дробный угол по системному времени; остановка при pause/AOD и удалении, запуск при resume. Реальная плавность и расход на Balance 2 требуют проверки на устройстве.

1.0.2: центры кругов (240,124), (124,240), (356,240), (240,356), равноудалены от оси на 116 px. Дуги шкал по 50°: 290–340, 20–70, 200–250, 110–160. Четыре равных кадра 200×200 для шкал. Дата из TIME day/month/week — отдельные символы по дуге радиуса 191, обновление MINUTEEND/resume, нормальный и AOD режимы.
